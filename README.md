# PasswordX

<p> A Java-based program that analyzes a user's password and determines its strength using length, character types, and security patterns. It provides a score, strength level, and suggestions for creating a stronger password.</p>

1. Checks password length
2. Detects uppercase and lowercase letters
3. Detects numbers and special characters
4. Detects repeated characters
5. Detects sequential patterns like 123 or abc
6. Detects common passwords
7. Calculates a security score from 0–100
8. Classifies passwords as Very Weak, Weak, Moderate, Strong, or Very Strong
9. Provides personalized suggestions to improve the password
10. Displays a detailed analysis of the password
